# Таксист Ашот

Сериал Reels: 2D-мультик, нарисованный кодом. Таксист Ашот с кавказским акцентом хитро и по-доброму учит пассажиров обращаться с деньгами. Пассажир в каждой серии новый.

**Цель:** объяснить деньги так, чтобы понял даже ребёнок. Каждая мысль показана через предмет из такси: таксометр — переплата, аренда машины — процент, навигатор — выбор стратегии.

## Порядок работы над серией

1. Тема и пассажир, новая папка `serii/NN-тема/`.
2. Сценарий, потом скилл `petlya-vovlechennosti`, потом `sud-prisyazhnyh`, потом правки.
3. Раскадровка картинкой и согласование.
4. Озвучка ElevenLabs (голоса в `GOLOSA.md`), сборка видео движком.
5. Обложка, описание, закреп с дисклеймером «не индивидуальная рекомендация».
