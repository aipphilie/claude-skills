# Озвучка: ElevenLabs (в т. ч. через Higgsfield)

## Голос
- Нужен ровный, спокойный, низкий мужской голос, «у костра», без рекламной бодрости.
- Voice Library → фильтры Language: Russian, Gender: Male, Age: Middle aged/Old,
  Use case: Narrative & Story / Audiobook. Поиск: deep, calm, narrator, storyteller.
- Сгенерировать одну и ту же фразу на 2–3 голосах и дать автору выбрать на слух (в исходном проекте
  победил голос «Влад»; англоязычный «Landon» звучал хуже на русском).
- Когда голос выбран, не меняй его и настройки во всех сериях (включи Save settings).

## Настройки
| Параметр | Значение | Почему |
|---|---|---|
| Stability | 55–65 % | ниже: переигрывает и «скачет»; выше: робот |
| Similarity | 75–80 % | выше: могут вылезти артефакты |
| Style (если есть) | 0–15 % | нам нужно спокойствие, а не драма |
| Speed (если есть) | 0.9–0.95 | медленнее = завораживает |
| Batch size | 2–3 | выбрать лучший дубль; 4 только для хука |
| Format | WAV, если есть, иначе MP3 | |

Вкладка **Voice Change** = автор начитывает сам, нейросеть меняет тембр, интонации остаются его.
Запасной план, если модель читает «не так».

## Подготовка текста
- Куски = сцены (8 кусков на серию). Генерировать по одному: неудачный дубль перегенерируется,
  не трогая остальное, а монтаж садится на паузы.
- Буква **ё** везде; ударения знаком «´» там, где модели ошибаются: при́нял, Се́верная.
  Если знак ломает чтение, убрать.
- Паузы: «…», перенос строки, «—». Цифры словами («два десять»).
- Названия в кавычках «Северная» читаются нормально.

## Теги (квадратные скобки, по-английски)
Берём **1–2 тега на кусок**, только в ключевых местах, иначе голос начинает играть:
`[slowly]`, `[softly]`, `[pause]`, `[whispering]` (для «Не отвечай»), `[sharp exhale]`.
Не берём: звуковые эффекты (`[heartbeat]`, `[echoing]`, `[knocking on door]`…), их делает монтаж
(можно управлять громкостью и временем), и «характерные» голоса (`[menacing]`, `[witch voice]`).
Если тег в середине строки игнорируется, перенеси его в начало строки.

## Приём кусков
Для каждого куска: длительность и паузы (`ffmpeg -af silencedetect=n=-38dB:d=0.15`), разметка
«время → фраза → картинка», короткий ответ автору. Если кульминация вышла быстрой, не проси
перегенерировать: раздвинь фразы тишиной в `timeline.py` (`"pauses"`).
Ты не слышишь аудио, поэтому проси автора проверить произношение спорных мест.

## Если ElevenLabs нет
Локальные варианты: RHVoice (`apt install rhvoice rhvoice-russian`, голоса aleksandr-hq, mikhail…)
звучит заметно механичнее. Нейросетевые Silero/Piper качаются с huggingface.co / models.silero.ai,
которые могут быть закрыты сетевой политикой окружения; тогда честно скажи, какой домен нужно открыть.
