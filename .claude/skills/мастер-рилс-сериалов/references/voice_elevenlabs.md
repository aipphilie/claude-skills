# Озвучка: ElevenLabs (в т. ч. через Higgsfield)

## Голос
- Нужен ровный, спокойный, низкий мужской голос, «у костра», без рекламной бодрости.
- Voice Library → фильтры Language: Russian, Gender: Male, Age: Middle aged/Old,
  Use case: Narrative & Story / Audiobook. Поиск: deep, calm, narrator, storyteller.
- Сгенерировать одну и ту же фразу на 2–3 голосах и дать автору выбрать на слух (в исходном проекте
  победил голос «Влад»; англоязычный «Landon» звучал хуже на русском).
- Когда голос выбран, не меняй его и настройки во всех сериях (включи Save settings).

## Настройки
| Параметр | Значение | Почему |
|---|---|---|
| Stability | 55–65 % | ниже: переигрывает и «скачет»; выше: робот |
| Similarity | 75–80 % | выше: могут вылезти артефакты |
| Style (если есть) | 0–15 % | нам нужно спокойствие, а не драма |
| Speed (если есть) | 0.9–0.95 | медленнее = завораживает |
| Batch size | 2–3 | выбрать лучший дубль; 4 только для хука |
| Format | WAV, если есть, иначе MP3 | |

Вкладка **Voice Change** = автор начитывает сам, нейросеть меняет тембр, интонации остаются его.
Запасной план, если модель читает «не так».

## Подготовка текста
- Куски = сцены (8 кусков на серию). Генерировать по одному: неудачный дубль перегенерируется,
  не трогая остальное, а монтаж садится на паузы.
- Буква **ё** везде; ударения знаком «´» там, где модели ошибаются: при́нял, Се́верная.
  Если знак ломает чтение, убрать.
- Паузы: «…», перенос строки, «—». Цифры словами («два десять»).
- Названия в кавычках «Северная» читаются нормально.

## Теги (квадратные скобки, по-английски)
Берём **1–2 тега на кусок**, только в ключевых местах, иначе голос начинает играть:
`[slowly]`, `[softly]`, `[pause]`, `[whispering]` (для «Не отвечай»), `[sharp exhale]`.
Не берём: звуковые эффекты (`[heartbeat]`, `[echoing]`, `[knocking on door]`…), их делает монтаж
(можно управлять громкостью и временем), и «характерные» голоса (`[menacing]`, `[witch voice]`).
Если тег в середине строки игнорируется, перенеси его в начало строки.

## Приём кусков
Для каждого куска: длительность и паузы (`ffmpeg -af silencedetect=n=-38dB:d=0.15`), разметка
«время → фраза → картинка», короткий ответ автору. Если кульминация вышла быстрой, не проси
перегенерировать: раздвинь фразы тишиной в `timeline.py` (`"pauses"`).
Ты не слышишь аудио, поэтому проси автора проверить произношение спорных мест.

## Если ElevenLabs нет
Локальные варианты: RHVoice (`apt install rhvoice rhvoice-russian`, голоса aleksandr-hq, mikhail…)
звучит заметно механичнее. Нейросетевые Silero/Piper качаются с huggingface.co / models.silero.ai,
которые могут быть закрыты сетевой политикой окружения; тогда честно скажи, какой домен нужно открыть.

## Озвучка самим Claude через Higgsfield CLI («112», серия 2)
Автор может попросить озвучить серию самому. ElevenLabs v4 доступен в Higgsfield (`higgsfield`, ставится хуком сессии).
1. **Вход из облачного контейнера.** `setsid nohup higgsfield auth login --port 8765 &`; ссылка на вход лежит в
   `/root/higgsfield-auth-*/sign-in.html` (meta refresh). Отправь её автору. После входа браузер автора упадёт на
   `http://localhost:8765/callback?code=…&state=…`: пусть пришлёт этот адрес целиком, а ты сделай `curl` по нему внутри
   контейнера. Ожидание длится ~5 минут, и `state=` должен совпадать с последней ссылкой (автор может прислать старый адрес).
   Потом `higgsfield workspace list` → `higgsfield workspace set <id>`.
2. **Голоса.** `higgsfield voices list` (имена без описаний; пол и возраст приходят в ответе генерации, `params.voices[0]`).
   Сначала пришли автору две короткие пробы («Привет, как дела?»), жди «ок».
3. **Генерация куска.** По одному куску, **последовательно** (12 параллельных вызовов CLI зависли):
   `higgsfield generate create elevenlabs_v4 --dialogue '[{"text":"…","voice_id":"<uuid>","voice_type":"preset"}]' --stability 0.6 --similarity_boost 0.78 --wait --json`
   → `result_url` (mp3). Теги `[slowly]`, `[pause]` работают и не читаются вслух.
4. **Проверка без ушей:** faster-whisper по каждому куску (см. `pipeline.md`): текст полный, теги не прочитаны.
5. **Темп.** Параметра скорости у модели нет; если серия длинная, ускорь диктора на монтаже
   `ffmpeg -af rubberband=tempo=1.1` (тембр не меняется).
6. **Ребёнок.** Детских пресетов нет, «young male» звучат как взрослые парни (F0 ≈ 135 Гц). Работает молодой женский
   голос (Pixie, F0 ≈ 215 Гц), поднятый на ~2,5 тона: `asetrate=44100*1.16,aresample=44100,atempo=0.862`, затем фильтр «телефона».
7. Голоса из трубки (сущность, ребёнок по телефону) прогоняй через фильтр «телефона» из `sound_design.md` до раскладки.
8. **Новый персонаж** (серия 3 «112»: та же героиня в 18 лет на кассете). Сгенерируй его реплику 5–6 женскими/мужскими
   пресетами (у пресетов нет описаний), выложи автору пробы с именами и жди выбор; автор выбрал Juno. До выбора
   строй таймлайн на любой пробе, потом замени файл и пересобери `timeline.py`.
9. **Параллельно — не больше 3 вызовов** (`xargs -P 3`): 12 сразу упали все, 3 проходят.
10. **«Кассета»:** фильтр «телефона» + `lowpass=3000`, `acrusher=bits=10`, `vibrato=f=0.9:d=0.04` (плавание плёнки).
11. **Звуковые эффекты** (плач младенца и т. п.): `higgsfield generate create mirelo_text_to_audio --prompt "…, starts immediately, loud" --duration 4 --wait --json`.
    Проверь громкость по секундам (`ffmpeg -ss N -t 1 … volumedetect`): первая попытка плача оказалась почти тишиной
    с одним пиком. Кладётся в `sound.json` событием `{"type":"file", …}` (см. `mix_audio.py`).
