# Саунд-дизайн

Ты не слышишь звук, поэтому дизайн строится по правилам и проверяется цифрами
(`silencedetect`, `volumedetect`, `ebur128`). Автор слушает и даёт обратную связь.

## Правила (каждое пришло из реальной правки автора)
1. **Никаких обрывов на склейке.** Улица ↔ помещение = кроссфейд 1–1,5 с. Звук может опережать
   картинку на 0,2–0,5 с (J-cut): ветер метели нарастает до того, как открылась дверь. При входе внутрь
   свист (высокие) уходит быстрее гула, будто закрылась дверь.
2. **Голос главный, но фон живой.** Под речью всё неголосовое (и фоны, и эффекты) тише на 30–40 %,
   не в разы. Плавно: уходит чуть раньше фразы, возвращается через ~0,4 с после.
3. **Эффекты умеренные.** Удары, гудки, порывы не должны выпрыгивать. Громкие акценты ставь
   в паузы между фразами.
4. **Сюжетная тишина**: резкий уход звука допустим как приём («…тишина», выдернутый шнур), но
   с коротким затуханием 0,05–0,45 с, а не щелчком.
5. **Громкость**: итог −14 LUFS (Instagram), true peak ≤ −1,5 dB.

## Палитра звуков (синтез в `scripts/mix_audio.py`)
| Тип | Где |
|---|---|
| `wind` / `storm` | улица; storm для метели |
| `room` | помещение: ветер за стеной + треск печи |
| `hum` | генератор (50 Гц), сеть приёмника (60 Гц, обрывается рывком шнура) |
| `drone` | низкий гул напряжения, растёт к финалу |
| `rotor` | вертолёт |
| `beep` | сигнал 1150 Гц, 0,13 с, «без помех», чисто |
| `thump` | удар на резких склейках и шоке |
| `whoosh` | шторка-ель |
| `ping` | радарные круги |
| `paper`, `marker`, `tick`, `step`, `knock`, `pop`, `creak` | фактура действий |

Хорошие записанные звуки (ветер, печь, шаги по снегу), если автор их найдёт, всегда богаче
синтеза: подмешивай их вместо соответствующих типов.
