# Визуальный стиль и приёмы анимации

## Эталон (разбор рилса «Плацкарт», который понравился автору)
1. **Субтитры — двигатель удержания**: центр, чуть ниже середины, жирный капс, 2–4 слова,
   смена каждые 0,5–1 с, караоке (непроизнесённое серое), жёлтый = цифры/факты, красный = угроза,
   «поп» появления (scale 1.07 → 1).
2. **Камера не стоит**: наезд 100 → 108 % за кадр, параллакс 2.5D по слоям (небо/горы/лес/передний план).
3. **HUD-гаджеты**: бумажный стикер с рукописным «Ночь 1 · 03:14», термометр в рамке, красный таймер
   обратного отсчёта, датчики на объектах, которые меняют цвет, номера глав-стикеры, прогресс-бары.
4. **Инфографика вместо картинки** каждые 8–15 с: карта сверху с радарными кругами
   «10/50/100 км — ни души», маршрут, который рисуется, разрез «кукольный домик», тепловизор,
   документ с красным кружком «от руки».
5. **Свет**: всё тёмно-синее, сильная виньетка, одно тёплое пятно с bloom, снег и зерно.
6. **Персонажи** простые, «марионеточная» анимация.
7. **Ритм**: картинка меняется каждые 2–4 с.

## Что добавляет The Long Dark
- Плоские формы, но края **рваные** (подразбить ребро и потрясти точки, функция `jag`).
- Гранёные горы: светлая и тёмная грань, снежная шапка двумя тонами (`mountain`).
- Ели ярусами треугольников со снегом на освещённой стороне (`pine`).
- Небо как главный герой: огромные градиенты; на рассвете бирюза → янтарь → розовый.
- Ветер: позёмка, косые штрихи метели (`streaks`), пар изо рта, дым по ветру.
- Живописная текстура поверх кадра (`PAINT`, режим overlay), зерно, виньетка (`finish`).
- Стиль берём, ассеты нет: никаких скриншотов игры, её локаций и логотипа.

## Каталог готовых сцен в примере (`assets/example_episode/episode.js` + `scripts/lib.js`)
| Сцена | Функция | Для чего |
|---|---|---|
| Приёмник крупно, шнур, будильник | `radio`, `cord`, `clockObj` | интерьерный объект с состояниями (вкл/выкл, вилка в розетке/на столе) |
| Портрет героя | `portrait` + `drawAndrey` | лампа, свет от шкалы снизу, моргание, взгляд, шок (`wide`), микрофон, затемнение |
| Общий план со станцией | `scene2` | небо, сияние, слои L1–L4, параллакс, окно, дым, мигающий огонь мачты |
| Карта сверху | `mapScene2` | лоу-поли местность, радиоволны, круги 100/200/300 км, пунктир к материку |
| Дни в журнале | `days` | перелистывание страниц + счётчик 1 → 47 |
| Выход в метель | `exitScene` | дверь со светом, фигура, циферблат «каждые 6 ч» |
| Верёвка 40 м | `ropeScene` | вид сбоку, столбы, линейка, которая рисуется |
| Рукавица отпускает | `mittenScene` | крупный план действия |
| Белая мгла | `whiteout` | шаги 1–5, свет двери гаснет, «ВИДИМОСТЬ: 2 М» |
| Бочки и шкала | `fuelScene` | сегментная шкала ресурса |
| Вертолёт на рассвете | `heliScene` | силуэт Ми-8, метка с выноской |
| «30 = 30», красная вспышка | `noErrorScene` | сравнение двух ресурсов |
| Осциллограф | `scope` | пусто / чистые три импульса |
| Дверь в темноте | `doorScene` | «будто из соседней комнаты» |
| Таймер 40:00 | `timerScene` | кольцо прогресса, красный в конце |
| Столбик времён | `timesScene` | цифры падают с «+40» |
| Полка с журналом | `shelfScene` | корешок рукописным шрифтом, подсветка |
| Страница журнала | `journalScene` | высокий лист, панорама вниз, круги маркером, «Не отвечай» с продавливанием |
| Финальная плашка | `endCard` | «часть 2 · ЖУРНАЛ · продолжение следует», три точки |
| Шторка-ель | `wipe2` | переход между сценами |

Фигура в полный рост (вид сбоку): `figure(g,x,y,scale,phase,{t,reach,flip})`, с развевающимся шарфом.
Персонаж-бюст: `drawAndrey(g,{hat:'ushanka'|'hood'|'beanie', beard:'full'|'stubble'|'grey'|'moustache',
coat:'parka'|'expedition'|'tulup'|'telogreika', scarf, glasses, headphones, old, look, blink, breath})`.
Для нового сериала меняй декорации (лес → двор, станция → многоэтажка), а приёмы оставляй.
