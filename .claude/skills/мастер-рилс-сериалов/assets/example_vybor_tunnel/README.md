# Пример: «ВЫБОР · Тоннель», серия 1 «Остановка»

Серия длиной 1:59, 1080×1920, 35 кадров. Всё нарисовано кодом, голос сделан в Higgsfield (ElevenLabs).
Это эталон **детализированного** стиля: реалистичная перспектива, живые лица и руки. Пример «Метеостанции» сделан в плоском рубленом стиле.

| Файл | Что внутри |
|---|---|
| `core.js` | утилиты, шумовые текстуры (дым, грязь, зерно), `smoke`/`smokeMasked`, `dust`, `finish`, LED-текст `ledText`, субтитры |
| `sonya.js` | персонаж-портрет `drawSonya(g,x,y,s,{v,t,open,look,rim,fill,dark,breath,brow})`: три причёски, глаза с радужкой, наушники за шеей |
| `scenes.js` | холодное открытие: героиня в проёме над тоннелем, LED-табло, колесо с искрами, дым из щели, глаз крупно с логотипом. `camTo` + глобальный `CAM` для повторного использования сцен с другой камерой |
| `wagon.js` | вагон метро в настоящей перспективе (`pj(X,Y,Z)`): сиденья, поручни, окна, двери, 15 пассажиров (сидят и стоят), версии со светом и в аварийном режиме, героиня со спины |
| `ep.js` | вся серия: таблица `SHOTS` (кадр ↔ фраза через `ps('04.3')`), крупные планы, руки (`finger`, `sleeve`), стрим, рация, динамик с осциллограммой по огибающей голоса, кнопка, памятка со штампом, контактный рельс, развилка А/Б, финальная карточка, субтитры `SUBTXT` |
| `covers.js` | 4 обложки (`coverFrame(n)`), выбрана 4 «Голос» → `../cover_example_vybor.jpg` |
| `timeline.py` | склейка кусков голоса с паузами, проверка «число пауз = число фраз», телефонный фильтр для голоса динамика → `timeline.js`, `voice.wav` |
| `sound.py` | весь саунд-дизайн на numpy (без scipy): подложки, пэд, синтезированные эффекты, приглушение фона под голосом |
| `render.js` | `stills t1,t2` / `covers` / `video out.mp4 dur [f0 f1]`: кусок кадров для параллельного рендера |

Порядок: `timeline.py` → `env.js` (огибающая голоса, см. `references/pipeline.md`) → stills-сетка →
4 параллельных `render.js video … f0 f1` → concat → `sound.py` → микс + loudnorm → сборка.
