# «Ипотека» — полная серия, v2 (~1:30–1:40)

v2 исправлена по петле вовлечённости и суду присяжных. Итоги суда — в `SUD-ipoteka-2min.md`, разбор v1 — в истории git.

**Цель:** чтобы даже человек без опыта понял, как работает ипотека, куда уходят деньги и как платить меньше. Каждая мысль объясняется через предмет из такси.

**Герои:** Ашот (жёсткий кавказский акцент, хитрый, добрый, умный) и пассажир Тимур, пацан 20–25.

**Расчёты** (аннуитет, проверены):

| Сценарий | Итог |
|---|---|
| База: 5 млн, 11%, 20 лет | платёж 51 609 ₽, выплат 12,39 млн (≈2,5 суммы кредита), переплата 7,39 млн |
| Первый год | заплачено 619 тыс.: 546 тыс. проценты, 73 тыс. в долг. Первый платёж: 45 833 процентов, ~5 800 в долг |
| +10 тыс./мес, «в срок» | закрыт за 12,4 года, экономия 3,19 млн |
| +10 тыс./мес, «в платёж» | экономия 1,63 млн |
| Ставка 10% вместо 11% | −806 тыс. |
| 10% и +20 тыс./мес «в срок» | −4,63 млн, закрыт за ~9,5 лет |
| Льготная 6% | выплат 8,6 млн |

**Как генерировать:**
- Реплики Ашота написаны «с акцентом» (э после согласных) только для голоса. **Цифры пишем без искажений**, чтобы не сливались.
- Субтитры делаются из нормальной орфографии.
- Каждая цифра, которая звучит, дублируется крупно на экране.
- «Дарагой» звучит 1 раз за ролик, «слюшай» не больше 1 раза.

**Ре-хуки** (каждые 10–20 сек): 0:13 шутка · 0:19 вопрос с мгновенным ответом · 0:37 «20 лет жизни» · 0:46 «что делать?» · 0:49 фокус · 1:03 «где взять?» · 1:14 «и последнее» · 1:25 финальный поворот.

**Фирменные сигналы сериала** (в каждой серии):
- имя «Ашот» в первые 3 сек;
- «Включаю счётчик» + щелчок таксометра;
- шкала «ОТЫГРАЛИ У БАНКА» появляется на «фокусе»;
- плашка-цитата с главной фразой («ЛЕГЧЕ — БАНКУ»);
- ритуал «С тэбя N рублэй… Совэт — бэсплатно»;
- шпаргалка + «скинь тому, кто…» + вопрос в комменты;
- тизер следующего пассажира.

**В закреп:** «Поправка для внимательных: переплата = платёж × число месяцев − сумма кредита. Её видно в графике платежей. ПСК в договоре — это годовая ставка с комиссиями и страховкой, не путать. Пример: 5 млн, 11%, 20 лет, аннуитет. У льготной ипотеки цифры другие, принцип тот же. Досрочка в РФ без штрафов, но банк нужно уведомить. Перед досрочкой оставь подушку. Не индивидуальная рекомендация. Легче — банку 😄»

**Хронометраж:** Ашот ~200 слов, Тимур ~30. При скорости 1.1 это ~1:35.

**Нарезки после выхода** (по 25–40 сек): 1) хук «две с половиной квартиры» + пицца; 2) «Легче — банку» + срок против платежа; 3) «всё вместе» + шпаргалка. В описании каждой ссылка на полную серию.
