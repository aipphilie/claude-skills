# Таксист Ашот

Вертикальные ролики 15–20 сек: пассажир говорит про деньги, Ашот хитро подкалывает и даёт совет, в конце панч «С тебя N рублей». Всё рисуется и двигается кодом, без ИИ-генераторов картинок и видео.

Пилотное ТЗ (сценарий, раскадровка, монтаж): `TZ-pilot-ipoteka.md`.

## Решения автора (главнее всего остального)

- **Ашот — вариант «Д» («Ашот-бизнесмен»)**: квадратная челюсть, щетина, нос с горбинкой, моржовые усы, густые брови, хитрый прищур, седые виски, тёмно-синяя кепка-восьмиклинка с тёмными очками на ней, тёмная рубашка с расстёгнутым воротом, волосы на груди, золотая цепочка. Лист эмоций: `assets/ashot-emocii.png`. Другие варианты (А–Г, отклонены): `assets/ashot-varianty.png`.
- **Пассажир меняется каждую серию** (пацан, тётя в возрасте, ребёнок…). Конструктор `engine/src/characters/Rider.tsx`, готовые типажи в `RIDERS`, лист `assets/passazhiry.png`. Новый типаж = новая запись в `RIDERS` из готовых деталей; если чего-то не хватает (платок, борода, кепка), дописываем деталь в конструктор, не рисуем персонажа с нуля.
- **Сначала показываем персонажей картинкой, потом делаем видео.** Новый пассажир или правка внешности → лист (`Sheet`/`Riders`) → согласование → только потом ролик.
- Озвучка вторична, автору важнее картинка.
- **Камера и зеркало**: зеркало заднего вида смотрит на водителя. Нельзя показывать отражение глаз Ашота, если камера стоит у лобового стекла и смотрит назад. Правильно: камера с переднего пассажирского сиденья (Ашот сбоку, пассажир сзади), зеркало видно сбоку; или отдельный план зеркала с точки водителя. В текущем `Cabin.tsx` это ещё НЕ исправлено.

## Движок (`engine/`)

Remotion 4 + React 18, всё в SVG. Мир 1080×1920, камера — `translate/scale` мира по списку планов.

```
cd engine && npm i
# голос: ElevenLabs при ELEVENLABS_API_KEY (+EL_ASHOT, EL_PASS — id голосов), иначе edge-tts (ru-RU-DmitryNeural, разный тон)
pip install edge-tts faster-whisper scipy
python3 tools/tts.py tools/lines.json public/voice
python3 tools/assemble.py tools/lines.json public/voice src/timeline.json public/voice.wav   # раскладка реплик, слова по ASR, амплитуда для липсинка
python3 tools/sfx.py src/story.json src/timeline.json public/voice.wav public/mix.wav         # поворотник, вжух, касса, музыка, приглушение, -14 LUFS
node tools/stills.mjs prev 0.4 1,3.5,6.7    # кадры в нужные секунды — смотреть глазами
python3 tools/sheet.py prev                  # склеить в лист
npx remotion still src/index.ts Sheet ashot.png      # лист эмоций Ашота
npx remotion still src/index.ts Riders riders.png    # лист пассажиров
npx remotion render src/index.ts Ashot out.mp4
```

Chromium: `remotion.config.ts` указывает на `/opt/pw-browsers/chromium_headless_shell-*/…/chrome-headless-shell` (переменная `REMOTION_CHROME`). Для edge-tts в облачном контейнере нужен CA прокси — `tts.py` берёт `SSL_CERT_FILE` или `/root/.ccr/ca-bundle.crt`; сервис иногда отвечает пусто, в скрипте есть повторы.

### Файлы

- `src/story.json` — **сценарий монтажа одной серии**: `cues` (событие → [реплика, номер слова, сдвиг]), `shots` (план камеры `[x, y, zoom]`, `move` — кадры наезда, `shake`, `whoosh`, `drift`), `keys` — слова, подсвеченные в субтитрах. Читают и Remotion, и `sfx.py`.
- `tools/lines.json` — реплики (`who`: ashot / passenger / passenger_shock).
- `src/characters/Ashot.tsx` — основная модель Ашота: поворот головы `turn` (черты лица сдвигаются, уши прячутся), брови, моргание, подмигивание, 4 формы рта, ухмылка, правая рука `rest / up (палец вверх) / palm (протягивает руку за деньгами)`, левая на руле. `AshotEyes` используется и для зеркала.
- `src/characters/AshotVariant.tsx` — параметрический анфас для подбора внешности (варианты А–Д).
- `src/characters/Rider.tsx` — конструктор пассажиров + эмоции `EMO` (calm, talk, worry, shock). `Passenger.tsx` — старый пацан, который пока стоит в `Video.tsx`; заменить на `RiderFigure`.
- `src/scene/Cabin.tsx` — салон: вечерний город с параллаксом в окнах, сиденья, руль, таксометр, зеркало с ёлочкой-освежителем.
- `src/overlays/Graphics.tsx` — инфографика серии «Ипотека» (5 млн → 12 млн+, домик + лента «20 лет», кнопки «платёж/срок» с рукой, штамп «400 ₽»). На каждую серию пишем свою.
- `src/overlays/Subtitles.tsx` — по 2–3 слова, Rubik 900, кремовые с шоколадной обводкой, ключевые слова горчичным, текущее слово крупнее, y≈1330–1590.
- `src/palette.ts` — палитра (тёплая, без кислотных цветов).

## Правила кадра

- 1080×1920, 30 fps. Важное только в зоне x 56–922, y 250–1600 (шапка и кнопки Reels).
- Смена плана или движение камеры каждые 1–2 сек. Инфографика сверху (y 300–800), лицо Ашота ниже неё — проверять по кадрам, чтобы плашки не закрывали кепку и лицо.
- Палец вверх рисовать сбоку кулака, рядом с большим пальцем — по центру кулака читается как неприличный жест.
- Стоп-кадр в конце: время замирает (`freeze` cue), вспышка, звук затвора.
