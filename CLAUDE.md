# Инструкции для Claude в этом репозитории

Владелец: Ярослав. Общаться с ним по-русски, коротко, по делу.

## Главный проект: канал «Не тупи» (netupi.tv)

Перед любой работой над роликами, каруселями, обложками или сценариями прочитай по порядку:

1. `ne-tupi/PERENOS.md` — сводка всех правил, голоса, где что лежит, что ещё не влито в main.
2. `ne-tupi/PRAVILA.md` — все утверждённые правила (персонаж, монтаж, звук, обложки, YouTube).
3. `ne-tupi/HUKI.md` — 20 фраз-хуков, в каждом сценарии 3–5 уместных.
4. `ne-tupi/pamyat/` — полная копия памяти старого проекта (история каждого ролика, решения и правки Ярослава). Начни с `pamyat/MEMORY.md`, нужные файлы открывай по теме.

Если правила где-то расходятся, верно то, что записано позже (даты в памяти). Новые правила от Ярослава записывай в `ne-tupi/PRAVILA.md` и в `ne-tupi/PERENOS.md` через PR.

## Как работаем

- Новые наработки (сценарии, код монтажа, обложки) сразу коммитить в ветку и открывать PR. Видео-рендеры (.mp4) и озвучку (.mp3) в репо не тащить, кроме эталонов.
- Ключ ElevenLabs берётся только из переменной окружения `ELEVENLABS_API_KEY`. В код и в репо его не вписывать.
- По любой новой идее по умолчанию делать короткий рилс 9:16 ≈60 сек. Длинное YouTube-видео только по прямой просьбе.

Другие папки (`taksist-ashot/`, `youtube-agent-skill/`, `.claude/skills/`) — отдельные проекты и скиллы.
