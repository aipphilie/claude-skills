# Ярик — Почему свой голос на записи бесит (v2, после петли вовлечённости)

Хронометраж: ~58 с · Режим: «Как избежать» · Цель: комментарии

## Разбор исходника по петле

```
ПЕТЛЯ: шок 6/10 · интрига 4/10 · пружина 5/10 · катарсис 7/10
Висящий вопрос (было): «почему голос на записи мерзкий» — закрывается уже на 0:20, дальше держать нечем.
Висящий вопрос (стало): «кто ещё слышит Ярика ВОТ ТАК?» — открывается на 0:07, закрывается на 0:40.
Где рвётся:
  0:00 — шок только словами, первый кадр статичный, нет звука-удара.
  0:12 — ответ «почему» сразу, без ступенек: интрига гаснет к 0:20.
  0:35 — поворот хороший, но вопрос под него не открыли заранее, он не бьёт как ответ.
  0:53 — «пишет только текстом» зритель угадывает сам, нет второго поворота.
Фирменные сигналы Ярика: имя в первые 3 с — есть; переход «заглянем к нему в башку» — не было; мостик в Telegram — не было.
```

## Что поменял

1. **Шок (0:00).** Ролик открывается самим голосовым Ярика: писклявое «Пацаны, здаро́ва!» + звук «дзынь» отправки + резкий зум на замершее лицо. Звук срабатывает раньше слов.
2. **Интрига (0:06).** Добавил фразу «Но самое страшное даже не это. А то, кто ещё слышит его ВОТ ТАК». Это и есть висящий вопрос, ответ на него — поворот «все: пацаны, мама, бывшая».
3. **Пружина (0:16–0:36).** Фирменный переход «А теперь заглянем к нему в башку» + счётчик на экране «ПУТЬ 1 / ПУТЬ 2» + шкала «бас 100% → 30%», когда микрофон срезает кости.
4. **Катарсис (0:36).** Поворот теперь отвечает на вопрос из 0:06 — зритель получает награду.
5. **Второй поворот в финале.** «Ярик теперь пишет пацанам только текстом. Пацаны думают, что он обиделся». Финал, который не угадать на 10-й секунде.
6. **Факты.** «Кости лучше передают низкие частоты» — правда (костная проводимость). «Через пару дней станет норм» смягчил до «со временем привыкает»: точных сроков наука не даёт.
7. **Мостик в Telegram** — только плашкой на экране, голосом не говорим, чтобы не глушить призыв в комменты.

## Фирменные сигналы (повторять в каждой серии)

- Переход «А теперь заглянем к нему в башку» + один и тот же звук «вжух».
- Тёмный фон внутри, шалфей с лучами на лайфхаке.
- Финальная интонация [playful] на вопросе зрителю.
