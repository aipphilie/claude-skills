# Как делаются английские версии длинных роликов (16:9)

Монтаж берётся из русской версии (ne-tupi-youtube/<ролик>/render/kod), а меняются только голос, тайминги и надписи.

1. `tts_en.py <ролик>` озвучивает ne-tupi-usa/<ролик>/ozvuchka-en.txt голосом Grant по главам (блоки через пустую строку) в `<ролик>/zvuk/chNN.json/mp3`. Русская разметка лежит в `<ролик>/zvuk_ru/`.
2. `tlmap.py` вставляется в kod/tl.py перед `if __name__`. Он подменяет `wt()`: якорное слово ищется в русской озвучке, по номеру предложения и месту внутри него переносится в английскую озвучку. Поэтому сцены (scenes.py) не надо переписывать под английские слова.
3. `trace.py <ролик>` записывает, какие русские строки работают как якоря (anchors.json), их не трогаем.
4. `<ролик>/tr_en.py` словарь «русская надпись → английская», `apply_tr.py <ролик>` заменяет все надписи, кроме якорей, и ₽ на $. Плюс вручную: `ГЛАВА {ch}` → `CHAPTER {ch}` в compose.py и gfx.py, кавычки в clean(), звуки ×0.5 в mix.py, в track.py английские гласные.
5. Из папки ролика: `python3 kod/voice.py`, `python3 kod/track.py`, `bash kod/render_ch.sh` (нужен http.server 8777 с 3d/), `python3 kod/mix.py`, `bash kod/render_v.sh` → final.mp4.

Готовый код каждого ролика: `<ролик>/kod/`, обложки `<ролик>/oblozhka/prevyu_en.py`, тексты для Studio: [../long-oformlenie.md](../long-oformlenie.md).
Английская озвучка и рендеры лежат в /mnt/project-files/ne-tupi-usa/<ролик>/render/ (в репо не кладём).
