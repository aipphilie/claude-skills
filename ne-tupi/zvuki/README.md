# Звуковые эффекты «Не тупи»

Библиотека фирменных звуков. **Применять во всех роликах** (рилсы, Shorts, YouTube), старые `render/zvuk/sfx/` больше не использовать (Ярослав, 2026-11-11).

Все звуки сгенерированы в ElevenLabs Sound Effects и подготовлены к монтажу: тишина в начале срезана (звук попадает ровно в кадр), пик выровнен до −1 dB.

## Громкость

- Правило канала: звуки в 2 раза тише прежнего (×0.5), голос как есть.
- Файлы отсюда громче старых `sfx/`, потому что выровнены по пику. В миксе бери базовую громкость v ≈ 0.3–0.5, итог с ×0.5 получается ≈ 0.15–0.25.
- Пример строки для `mix.py`: `('zvuki/23-vzhuh-bas-a', T['dver'], 0.4)` → `volume={v*0.5}`.

## Как сделать новый звук

`syrye/gen1.py`, `syrye/gen2.py`: запрос `POST https://api.elevenlabs.io/v1/sound-generation`, модель `eleven_text_to_sound_v2`, `prompt_influence` 0.6–0.8, `duration_seconds` 0.5–3, формат `mp3_44100_128`. Ключ берётся из `ELEVENLABS_API_KEY`. Тексты всех запросов лежат в `syrye/prompts.json`. Цена около 11 кредитов за звук.

Нормализация после генерации:
```
ffmpeg -i in.mp3 -af "silenceremove=start_periods=1:start_threshold=-60dB,volume=<до пика −1 dB>" -ar 44100 -b:a 192k out.mp3
```
