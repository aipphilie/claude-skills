# «Не тупи» — папка проекта

Канал «Не тупи» (netupi.tv): твой личный ассистент по жизни. Рилсы 9:16 и длинные YouTube-ролики 16:9, персонаж — чёрный человечек на белом фоне.

**Начинать с [PRAVILA.md](PRAVILA.md)** — все утверждённые правила по персонажу, монтажу, голосу, обложкам и YouTube. Концепция канала — [KONCEPCIYA.md](KONCEPCIYA.md).

| Папка | Что внутри |
|---|---|
| `CHELOVECHEK.md` | Описание персонажа и как запускать рендер анимаций |
| `koncept/`, `rig.py` | Утверждённый концепт человечка и 2D-риг |
| `3d/` | 3D-модель (Three.js, стиль flat), повороты |
| `animacii/`, `anim.py`, `grid.py` | 15 анимаций 2D, GIF и MP4 |
| `animacii-3d/`, `anim3d.py`, `grid3d.py` | 19 анимаций с 3D-модели (+поворот, шаг в профиль, тащит груз в гору тяжело/легко), GIF и MP4 |
| `idei/` | Идеи рилсов (v1, v2), сценарии и тексты озвучки «Кофе тебя не разоряет» и «Зарплата пришла — зарплата ушла» |
| `zvuki/` | Библиотека звуковых эффектов (43 звука из ElevenLabs), применять во всех роликах |
| `render/` | Конвейер монтажа рилсов (код, README с порядком запуска), обложки, звуковые эффекты, одобренный рендер `kofe-test-v4.mp4` |
| `steklo/` | Эффект «жидкое стекло» (линза-лупа), движок и примеры |
| `golos/` | Выбор голоса ElevenLabs: журнал, пробные голоса |
| `branding/` | Аватарки, тексты для профилей |
| `youtube/` | Разбор правил YouTube, превью и названия, голос канала, идеи; ролики «Тебе 30, и ты не знаешь, чего хочешь» и «Почему ты всем говоришь "да"» (сценарии, озвучка, упаковка, превью, код монтажа 16:9) |

## Что не залито

Чтобы не раздувать репо, здесь нет готовых видео-рендеров (кроме эталонного `render/kofe-test-v4.mp4` и примеров стекла) и сгенерированной озвучки (`zvuk/ch*.mp3`, `voice.mp3`, `mix.m4a`). Озвучка пересоздаётся из `ozvuchka-*.txt` скриптом `tts.py` (нужен `ELEVENLABS_API_KEY`), видео — конвейером из `render/`.
