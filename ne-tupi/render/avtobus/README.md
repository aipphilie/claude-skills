# v2 (2026-11-14): монтаж круче — три приёма, которые выбрал Ярослав

- Смена темпа: голос ×1.10 (в v1 ×1.08), а в трёх местах вставлена тишина (pauzy.py → pauzy.json, тайминги в align2.json сдвинуты): 0,75 сек перед «Миллион в месяц» (силуэт миллионера в двери), 0,95 сек после «Стоп.» (застывший кадр), 0,65 сек после «не провал». В паузу нет звуков, медленный наезд и виньетка. Между паузами пулемёт: добавлены склейки (толпа крупно, «НАПРАВО» стрелкой, «МНОГО» отдельным кадром, цифра медианы на весь кадр).
- Переходы через действие (ACTION в compose_b.py, окно 0,1 до и 0,3 после склейки): push — человечек толкает старый кадр; zoomthru — пролёт сквозь предмет (в дверь автобуса, в хвост горы, в зелёного человечка медианы) с размытием; door — двери автобуса закрываются и открываются уже новой сценой; bodywipe — огромный идущий человечек как шторка; drop — новый кадр падает сверху.
