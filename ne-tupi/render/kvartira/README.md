# «Отцу квартиру дали» (почему отец с квартирой, а ты нет) v1 (2026-11-15)
- kvartira-v1.mp4 — 1080x1920, 30 fps, 64 сек, 42 сцены. Голос hU3rD0Yk7DoiYULTX1pD, eleven_v4, без ускорения. Звуки из ne-tupi-zvuki/gotovye ×0.5 (89 событий). Музыки нет.
- По присланному Ярославом чужому рилсу «Почему ты уже никогда не купишь квартиру». Сценарий переписан: отец квартиру не купил, ему её дали; аренда как подписка; совет «сначала плати себе». Что изменено и источники: ne-tupi/idei/kvartira/scenariy-v1.md.
- КАДР НА ВЕСЬ ЭКРАН, БЕЗ ЧЁРНЫХ ПОЛОС (просьба Ярослава: «не делай чёрные рамки, как у автобуса»). Белый фон с параллаксом на весь кадр, сцена рисуется сразу в 1080x1920: заголовок y≈370–600, фигуры до y=1270 (пол), субтитр y=1432. Безопасные зоны Reels соблюдены. Всё по центру x=540.
- Движок: kod/base_k.py (рисовалки и простые переходы из drop/kod/compose_d.py, пересчитанные под полный кадр) + kod/compose_k.py (предметы, 42 сцены, переходы через действие, глубина, субтитры). Переходы и depth() те же, что в «Автобусе» v2, но на весь кадр; двери — деревянные межкомнатные.
- Субтитры на белом: чёрный текст с белой обводкой, текущее слово на жёлтой плашке #FFD60A (sub_img — фиксированная базовая линия, слова не прыгают).
- НОВЫЙ ПЕРСОНАЖ — ОТЕЦ: серая кепка + светлые усы, чуть шире (dad=1, bw 1.12, th 0.98, lh 0.95 в kod/3d/index.html). Клипы d_idle, d_hips, d_shrug, d_wave, d_armsup, d_reach, d_keys в clips.py. Новые клипы героя: self (показывает на себя), think, give.
- Кадр человечка теперь режется на всю ширину (CROP 0..1080), чтобы не обрезались вытянутые руки.
- Нарисованные предметы (compose_k.py): block (панелька), flat (квартира в разрезе, 1 или 3 комнаты), keys, factory (завод с дымом), kiosk (окошко выдачи со шторкой), doc (ордер/документ), calendar, lock, coin/coinstack, wad (пачка купюр), tv, seat (кресло с подогревом), safe, speech/cloud, cursor, note, table/dish, room/sky (фоны), phone_big + row.
- Порядок: из kod/ python3 -m http.server 8777 → tts.py → clips.py → node 3d/frames.js clips.json kadry flat → compose_k.py (sheet 0.75 — лист сцен; числа — превью) → ./run_all.sh (4 куска параллельно, склейка, mix_k.py, итоговый mp4) → cover_k.py.
- Обложки: oblozhka/ (A «ОН ЕЁ НЕ КУПИЛ» — рекомендую, B «АРЕНДА = ПОДПИСКА»). Описание: ne-tupi/idei/kvartira/opisanie.md.
