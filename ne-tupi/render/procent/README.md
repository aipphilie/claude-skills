# «Первый миллион и десятый» (сложный процент) v1 (2026-11-12)
- procent-v1.mp4 — 1080x1920, 24 fps, 72 сек. Голос hU3rD0Yk7DoiYULTX1pD, eleven_v4. Сценарий и таблица расчёта: ne-tupi-idei/procent/scenariy-v1.md, подпись: opisanie.md.
- Формат присланного рилса: постоянная шапка «ПЕРВЫЙ МИЛЛИОН / И ДЕСЯТЫЙ», белая карточка со сменными сценами (гора с монетами, прямая «как думает большинство», живой график свои/проценты со столбиками «месяцев на каждый миллион», снежный ком, пирог 4/6 млн, столбики «каждый месяц» ×4, вопрос в комменты). Палитра белый / оранжевый #FF7A00 / чёрный / красный.
- Расчёт честный и считается прямо в compose_p.py: 25 000 ₽ в начале месяца, 12%/12 в месяц, ежемесячная капитализация. Плашка «без учёта инфляции и налога на доходы» весь ролик, «не является ИИР» первые 5 сек.
- Порядок (из kod/, PYTHONPATH на папку с anim3d.py/anim.py/rig.py): `python3 -m http.server 8777` → tts.py → вставка паузы перед «Всё. Не тупи» (align2.json) → track_p.py → `node 3d/frames.js track.json kadry flat 1080 1920` → compose_p.py (PART=0..3 PARTS=4) → mix_p.py → склейка part*.mp4 + mix.m4a.
- Обложки (стиль канала, жёлтые плашки): A «ДЕСЯТЫЙ ЗА 8 МЕСЯЦЕВ» (рекомендую, продолжение залетевшего «Десятый легче»), B «25 000 В МЕСЯЦ → 10 МЛН».
