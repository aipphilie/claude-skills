# «Вы даже не встречались. Чё так больно?»

Сценарий про отношения, которых не случилось, и будущее, с которым приходится прощаться. 30 планов. Полноэкранный движок «Автокредита» из PR #61, точные тайминги ElevenLabs, исходная модель «Не тупи». Для истории добавлены чемодан, ключ, билет, фотография, кухня и пляж. Ключ ведёт в пролёт через замочную скважину, скатерть открывает пляж, а пляж складывается в телефон. Звуки из библиотеки канала.

## Сборка

Нужны Python с Pillow, NumPy и CairoSVG, Node с Playwright, Chromium, curl и FFmpeg. Для новой озвучки нужен ключ `ELEVENLABS_API_KEY` в окружении. По умолчанию используется `/usr/bin/chromium`. Путь можно задать через `CHROMIUM_BIN`.

```sh
NETUPI_WORK=/tmp/ne-tupi-nebylo-work NETUPI_OUTPUT=/tmp/ne-tupi-nebylo-out bash build.sh
```

Если сохранить `voice.mp3` и `align2.json` в рабочей папке, сборка использует их повторно. MP4, две обложки и подпись сохраняются в папке вывода. Лист сцен остаётся в рабочей папке.
