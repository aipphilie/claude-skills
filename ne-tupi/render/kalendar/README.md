# «Листок на 66 тысяч» (календарь-копилка) v1 (2026-11-12)
- kalendar-v1.mp4 — 1080x1920, 24 fps, 63 сек. Голос hU3rD0Yk7DoiYULTX1pD, eleven_v4. Сценарий: ne-tupi-idei/kalendar/scenariy-v1.md.
- Формат присланного рилса: календарь сквозной нитью (8 появлений), коллаж-карточки «мелко + КРУПНО» на серо-голубом полутоне, триптих, красные штампы («ВСЁ.», «ПОСЧИТАНО»), разбитая копилка вместо цепи, финальная карточка-«кубок».
- Новое: белая «стикерная» обводка человечка (как у вырезок в оригинале, нужна поверх чёрного календаря), отъезд от листка к девятиэтажке со сварщиком на люльке, свои позы paint / holdup / holdjump / paintup в track_k.py.
- Порядок: из kod/ при запущенном `python3 -m http.server 8777` → track_k.py → `node 3d/frames.js track.json kadry flat 1080 1920` → compose_k.py (можно частями: PART=0..3 PARTS=4, потом склеить part*.mp4) → mix_k.py → склейка ffmpeg с mix.m4a.
- zvuk/voice.wav — озвучка с паузой 1,2 сек перед «Всё. Не тупи», kod/align2.json сдвинут.
- Обложки: oblozhka/ (A «ЛИСТОК НА 66К» — рекомендую, B «ЗАКРАСЬ КРУЖОК»), код cover_k.py.
