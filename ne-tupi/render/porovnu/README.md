# «Тебе заплатили твоими же деньгами»

Русский рилс 9:16. Голос канала, Eleven v4 с тегами интонации. Три друга делят чек за еду, а такси за общим заказом оплачивает один. Суммы условные: 2 700 ₽ за еду и 300 ₽ за такси. Еда поровну даёт 900 / 900 / 1 200 ₽ с учётом поездки. Если все заранее согласны делить поездку, получается по 1 000 ₽ на человека.

Монтаж использует анимации человечка из `animacii-3d/gif`, динамичные крупности, пословные субтитры по ElevenLabs и эффекты из `zvuki`. Обложка A «Скинулись поровну» и обложка B «900 / 900 / 1 200 ₽».

## Сборка

Нужны Python с Pillow и NumPy, FFmpeg, шрифт DejaVu Sans и `ELEVENLABS_API_KEY` в окружении. Из этой папки:

```sh
python tts.py /tmp/ne-tupi-porovnu
python render.py /tmp/ne-tupi-porovnu/voice.mp3 /tmp/ne-tupi-porovnu/alignment.json /tmp/ne-tupi-porovnu
```
