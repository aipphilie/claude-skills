# Перенос «Не тупи» на другой аккаунт Claude Code

Собрано 2026-11-22. Здесь всё, что нужно, чтобы на новом аккаунте Claude сразу делал ролики так же, как в старом проекте: инструкция по шагам, сводка правил и список того, что лежит вне репозитория.

---

## 1. Пошагово: как завести новый аккаунт

### Шаг 1. Свежие наработки уже в main

2026-11-22 в main влиты PR #48 (движок «Квартиры», кадр на весь экран, отец), #56 (официант, аристократ), #57 («Казино», серый человечек), #58 («Диван», frames.js без сервера), #60 (идеи v9, «Свобода», счётчик вопросов), #61 («Автокредит»), #63 (пёс, кошка, кот) и этот PR. Новый Claude работает с веткой `main` и видит всё это.

Ещё открыты старые PR со сценариями и идеями (#25, #27, #29–#31, #34, #35) и шуточный «Пряник» (#62). Для работы они не обязательны; HUKI.md из #25 уже скопирован сюда.

### Шаг 2. Доступ к репозиторию

- **Проще всего:** на новом аккаунте Claude подключи **тот же GitHub** (`aipphilie`): claude.ai/code → подключить GitHub → установить Claude GitHub App на репозиторий `claude-skills`.
- **Если у нового аккаунта свой GitHub:** на github.com/aipphilie/claude-skills → Settings → Collaborators → Add people → впиши его ник → он принимает приглашение на почте. Потом на новом аккаунте Claude подключить этот GitHub и установить Claude GitHub App на репо.

### Шаг 3. Облачная среда и ключ ElevenLabs

1. На claude.ai/code создай проект (или среду) и добавь репозиторий `aipphilie/claude-skills`.
2. В настройках облачной среды (шестерёнка рядом со средой) добавь переменную окружения **`ELEVENLABS_API_KEY`** со своим ключом. Ключ вписываешь только туда сам, в чат и в репо не вставлять.
3. Сеть: нужен доступ к `api.elevenlabs.io`, а также к pip и npm (для установки библиотек). Проще выбрать полный доступ в интернет или добавить эти хосты в список разрешённых.
4. Скрипт установки (setup script) среды, чтобы рендер завёлся сразу:
   ```bash
   pip install cairosvg pillow numpy
   command -v ffmpeg || (apt-get update && apt-get install -y ffmpeg)
   ```
   Chromium и Playwright (для рендера 3D-кадров человечка) в облачной среде Claude уже стоят.

### Шаг 4. Первый запуск

Напиши новому Claude, например:

> Прочитай CLAUDE.md, ne-tupi/PERENOS.md и ne-tupi/PRAVILA.md. Потом сделай рилс на тему «...» в стиле канала.

Файл `CLAUDE.md` в корне репо Claude Code читает сам при старте, он и отправит его к этим правилам.

Для проверки, что всё работает, можно попросить: «отрендери 3 секунды человечка, который машет, и озвучь фразу "Всё. Не тупи." голосом канала».

## 5. Главные правила (коротко)

Полностью в `PRAVILA.md`. Самое важное, что новый Claude должен соблюдать с первого ролика:

**Формат и сценарий**
- По умолчанию рилс 9:16 ≈60 сек. Длинное YouTube только по прямой просьбе.
- Каркас: шок → «Стоп. Тут ты тупишь.» → почему мозг так делает → как исправить → панч → «Всё. Не тупи.»
- Тон: старший друг с подколом, без унижения и занудства.
- Первые 3 сек: вопрос-тема ролика голосом и крупной плашкой + обещание. Эмоция про тему, не крик без смысла.
- Лестница вопросов: главный вопрос сразу, ответ в конце; в середине 2–3 пронумерованных вопроса со счётчиком 1-2-3.
- В каждом сценарии 3–5 хуков из `HUKI.md`.
- Мат пробно и дозированно (3–4 раза), в субтитрах через звёздочку (Х*Й).
- Никаких выдуманных цифр, факты с источниками.
- Когда Ярослав присылает чужой рилс или готовый сценарий, сразу делать готовое видео без отдельного одобрения сценария; правки он даёт на готовом.

**Монтаж**
- Всё в кадре строго по центру x=540 (плашки, карточки, группы, сетки).
- Без чёрных полос сверху и снизу: кадр на весь экран на белом фоне. Предметы и окружение отрисовывать, а не заменять текстом.
- СДВГ-монтаж: переходы через действие (push, zoomthru, door, bodywipe, drop) + глубина кадра (параллакс, тени, зерно). Пауз в тишине не ставить (`PAUSES = []`).
- Подсветка субтитров и фирменные плашки всегда жёлтые `#FFD60A`, при любой палитре.
- Субтитры до 2 строк под человечком. Безопасные зоны Reels: сверху 250 px, снизу ~390 px, справа 140 px.
- Персонаж толкает предмет лицом вперёд.
- Звуки только из `zvuki/`, громкость ×0.5, голос как есть.
- Жидкое стекло больше не использовать.

**Плашки-дисклеймеры (первые 5 сек)**
- Ролики про инвестиции: «Не является индивидуальной инвестиционной рекомендацией».
- Схемы, обнал, дропы: «Все персонажи вымышлены. Ролик основан на открытых источниках и не является инструкцией» + источники в описании, без реальных названий и шагов «как сделать». Слово «отмыв» не говорим, вместо него «прачечная / стирка денег».
- Сатира: «Сатира. Все персонажи вымышлены. Не является инструкцией».
- NE VPN: без «обхода блокировок» и «открой Instagram», упор на защиту и шифрование.

**Обложки и оформление**
- Обложки сюжетные: человечек что-то делает, белый фон, чёрное + жёлтые плашки. Всегда два варианта A (рекомендованный) и B.
- Ник везде netupi.tv. Аватарка `branding/avatarki/avatarka-final.png`.

**Языки**
- Instagram и русский YouTube: по-русски, рубли.
- Английский YouTube: всё на английском, адаптация под США (доллары, американские реалии), не дословный перевод; при честной несостыковке спросить Ярослава. По EN-версиям можно решать самому.
- Пояснения, README и инструкции для Ярослава всегда по-русски.

## 6. Что лежит только в старом проекте (не в репо)

Общая папка старого проекта (`/mnt/project-files/`, ~1,8 ГБ) на новый аккаунт сама не переедет. Для **новых** роликов она не нужна: код, правила, персонажи и звуки есть в репо, озвучка пересоздаётся из текстов.

| Папка | Размер | Что там | Нужно ли |
|---|---|---|---|
| `ne-tupi-render/` | 1,3 ГБ | готовые mp4 всех роликов, кадры, озвучка, обложки PNG | только как архив готовых видео |
| `ne-tupi-youtube/` | 216 МБ | рендеры длинных роликов | архив |
| `ne-tupi-usa/` | 159 МБ | EN-рендеры 9 роликов | архив |
| `uploads/` | 86 МБ | присланные тобой файлы и чужие рилсы | архив |
| `chelovechek/` | 59 МБ | ранние концепты человечка | уже в репо |
| `ne-tupi-zvuki/` | 5 МБ | звуки (в репо 43; №44 «ангелы-хор» и №45 «укус-хрум» есть только здесь) | по желанию |
| остальное (`ne-tupi-idei`, `-branding`, `-karuseli`, `-threads`, `-golos`, `ne-vpn`) | ~10 МБ | тексты, сценарии, картинки | почти всё уже в репо |

**Как забрать готовые видео:** открой старый проект в приложении Claude → Library и скачай нужные файлы. Или попроси Claude в старом проекте скопировать нужные ролики на компьютер в папку `D:\Claude`.

**Память старого проекта** скопирована в `ne-tupi/pamyat/` (37 файлов, состояние на 2026-11-22). Пути вида `/mnt/project-files/...` в ней указывают на старую папку и на новом аккаунте не откроются; соответствующий код почти всегда лежит в репо по тому же имени ролика: `ne-tupi/render/<ролик>/`, `ne-tupi/idei/<ролик>/`.
