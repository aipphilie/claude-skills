Формат: 9:16, ~60 сек, русский. Голос ElevenLabs `hU3rD0Yk7DoiYULTX1pD`, Eleven v4.
Герой: Пряник (новый персонаж, концепт в `koncept/`). Пряник молчит, его реакции идут пузырями на экране. Говорит закадровый голос: старший друг, который подкалывает.

## Проверка фактов (сверено с документацией Claude Code, code.claude.com/docs, 2026-11-21)

- `/init` анализирует проект и создаёт стартовый `CLAUDE.md`; файл загружается в начале каждой сессии. Править: `/memory`. Есть ещё «авто-память» — Claude сам сохраняет заметки, если сказать «запомни».
- `claude --continue` продолжает последний разговор, `claude --resume` даёт выбрать из списка.
- Remote Control: `claude remote-control` (или `/rc` внутри сессии) показывает ссылку и QR-код; продолжать можно на claude.ai/code или в приложении Claude (раздел Code). Код и файлы остаются на твоём компьютере, комп должен быть включён. Нужен платный план Claude (Pro и выше), с API-ключом не работает.
- GitHub: подключается на claude.ai/connect-github, репозиторий добавляется к проекту; так работает Claude Code в облаке (claude.ai/code).
- «Remotion Control» из ТЗ = Remote Control.

## Подпись (черновик)

Пряник впервые открыл Claude Code, а Claude его забыл через день. 3 настройки, чтобы он не терял контекст: репозиторий, CLAUDE.md, порядок в чатах + Remote Control. Сохрани, пригодится.
