# «Тебе 30, и ты не знаешь, чего хочешь» — рендер v1 (2026-11-08)
- ne-znayu-v1.mp4 — 1920x1080, 24 fps, ≈10,6 мин. Текст ozvuchka-v3.txt, голос hU3rD0Yk7DoiYULTX1pD (eleven_v3, mp3 128 kbps — 192 на тарифе недоступен).
- zvuk/ — озвучка по главам (ch00 холодный старт … ch09 финал) + тайминги по буквам.
- kod/ — конвейер 16:9 на базе рилсов v4:
  - tts.py — озвучка по главам; voice.py — склейка глав с паузами 1,6 с (там заставка главы).
  - tl.py — общая шкала времени, слова, поиск времени слова wt(глава, слово, k).
  - scenes.py — 64 сцены: сторона человечка (L/R/C), масштаб, анимации, элементы графики по словам.
  - gfx.py — элементы: плашки, карточки, эмодзи, облака мыслей, перекрёсток, счётчик, столбики, батарейка и т. д.
  - track.py — позы + рот → track.json; frames2.js — кадры персонажа (720x1280, нужен http.server 8777 в папке с 3d/ и three.module.js 0.160).
  - compose.py — сборка кадра: фон, графика, субтитры под человечком (до 2 строк, на подложке), плашка главы слева сверху, персонаж multiply. `python3 compose.py prev 12.5 40` — превью кадров.
  - mix.py — голос + звуки из ne-tupi-render/zvuk/sfx.
- Порядок: tts.py → voice.py → track.py → render_ch.sh → mix.py → render_v.sh.
- Музыки пока нет.
