# Не тупи — проект для Claude Code

## Суть проекта

Канал «Не тупи» в формате «твой личный коуч». Главная тема — психология, дополнительно деньги и немного здоровья, но всё подаётся через психологию (например, «почему ты сливаешь бабки», «почему не можешь начать спорт»). Проект новый, делается с нуля.

Ник на всех площадках: **netupi.tv**.

## Аудитория

- Возраст 18–35, пол любой.
- Обычный человек, у которого повседневные проблемы.
- Правило: каждый ролик разбирает реальную бытовую проблему, знакомую зрителю.

## Тон

Старший друг с подколом. Сначала по-дружески стебём зрителя («опять в три ночи в телефоне залип, ну ты гений»), потом объясняем, почему так происходит, и даём рабочий совет. Без унижения и без занудства. Контент должен быть вирусным и трендовым, чтобы зритель досматривал.

## Визуал

- Белый фон.
- Чёрный человечек: сглаженный, без острых углов, без пальцев, две руки и две ноги. Из деталей максимум открывающийся рот.
- Человечек сам рассказывает и показывает всё жестами.

## Озвучка

- ElevenLabs, мужской голос.
- Говорит сам человечек, рот двигается под речь.
- Пользователь даёт только API-ключ ElevenLabs.

## Площадки и форматы

- YouTube: длинные ролики по 8–10 минут, длина зависит от темы. Три ролика в неделю.
- YouTube Shorts и Instagram Reels: нарезки из длинных роликов, до трёх в день.

## Производство (всё делает Claude Code)

- Сценарий, озвучка через API ElevenLabs, анимация и сборка видео делаются кодом (например, Remotion).
- Сначала один раз собрать базу: модель человечка, набор поз и жестов, анимацию рта под озвучку, шаблоны текста на экране. Дальше ролики собираются по шаблону.
- Нарезки для Shorts и Reels делаются автоматически из длинного ролика, в вертикальном формате.
- Если нужен доп. монтаж, пользователь просит доработать или правит сам.

## Превью для YouTube

Превью — половина успеха ролика. Для каждого видео Claude Code рисует превью кодом (SVG/HTML → PNG): человечек в выразительной позе, крупный короткий текст, яркая эмоция. Превью должно передавать суть ролика и вызывать желание кликнуть.

## Темы и ограничения

- Темы любые.
- Наркотики по минимуму. Если тема их касается, заменяем слово (например, «котики»). Идеи на такие темы можно предлагать, решает пользователь.

## Монетизация

Пока без чёткого плана. Сначала охваты, трафик в Telegram, потом реклама.

## Без жюри

AI-жюри для проверки сценариев в этом проекте не используется.
